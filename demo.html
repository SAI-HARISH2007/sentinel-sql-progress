3 · Architecture

Hover a box for its columns, click one to replay the flow. Violet marks the code that runs without anyone calling it.

  • Atomic. The trigger runs inside the INSERT's own transaction: no scored transaction without its alert, and a scoring error rolls back the insert.
  • Tunable. Thresholds are rows in rule_config; the procedure reads them on every call.
  • Explainable. Each rule that fires appends its own text to the JSON reasons array.
